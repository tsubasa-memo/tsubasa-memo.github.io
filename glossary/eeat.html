E-E-A-Tとは？コンテンツ品質の4つの評価要素

2026年05月16日

E-E-A-Tとは

E-E-A-Tは、Googleがコンテンツの品質を評価する際に重視する4つの要素の頭文字だ。Experience（経験）、Expertise（専門性）、Authoritativeness（権威性）、Trustworthiness（信頼性）の4つで構成される。

Googleの「有用で信頼性の高いコンテンツの作成」ガイドでは、「コンテンツ作成者が、そのトピックに関する十分な実体験を持っていることが重要」と記載されている。もともとE-A-T（3要素）だったが、2022年12月にExperience（経験）が追加されてE-E-A-Tになった。

外 有用で信頼性の高いコンテンツの作成 - Google developers.google.com

注意すべきなのは、E-E-A-Tは検索アルゴリズムの直接的なランキングシグナルではないという点だ。GoogleのSEOスターターガイドでも、E-E-A-Tは品質評価ガイドライン（人間の評価者向けの指針）に含まれる概念であり、アルゴリズムが直接E-E-A-Tスコアを計算しているわけではないと説明されている。ただし、E-E-A-Tが高いコンテンツは結果的に検索順位が上がりやすい傾向にある。

外 SEOスターターガイド - Google developers.google.com

4つの要素の意味

Experience（経験）

書き手がそのテーマについて実際に体験しているかどうか。商品レビューなら実際に使った感想、サービス比較なら実際に問い合わせや見積もりを取った経験があると評価が高くなる。

Expertise（専門性）

そのテーマに関する知識の深さ。医療・法律・金融（YMYL領域）では資格や実務経験が重要だが、それ以外の分野では「十分に調べた上で正確な情報を書いている」ことでも専門性を示せる。

Authoritativeness（権威性）

書き手やサイトがそのテーマで信頼される存在として認知されているかどうか。被リンクの数や質、他サイトからの言及、サイトの運営歴などが影響する。

Trustworthiness（信頼性）

4つの中で最も重要とされている要素。サイトが安全であること（HTTPS対応）、運営者情報が明示されていること、情報の出典が明確であること、などが含まれる。

web.devのCore Web Vitals解説も参考になる。ページの表示速度や操作性も、広い意味でのユーザー信頼につながる要素だ。

外 Core Web Vitals - web.dev web.dev

個人ブログでE-E-A-Tを高めるには

企業サイトと違って個人ブログは権威性が弱い。そこを補うために自分がやっていることは3つある。

1つ目は、実体験を書くこと。「使ってみた」「調べてみた」「比較してみた」という一次情報がExperienceになる。試していないことを試したように書かないのが前提だ。

2つ目は、出典を明示すること。公式ドキュメントや一次ソースへのリンクを本文中に貼ることで、情報の信頼性を補強する。「○○の公式サイトによると〜」という引用形式を使っている。

3つ目は、運営者情報を公開すること。このブログでは運営者情報ページを用意し、プライバシーポリシーも設置している。匿名ブログでも最低限の運営者情報を開示していれば、Trustworthinessの評価に寄与する。
